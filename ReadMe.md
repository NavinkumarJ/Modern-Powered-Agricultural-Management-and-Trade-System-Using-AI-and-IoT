
# 🌾 Modern Powered Agricultural Management and Trade System Using AI and IoT
### _AI-Powered Farming • Smart Trading • Intelligent Decision Support_

---

## 🚀 Overview
The **Smart Agriculture Management & Trade System (SAMTS)** is a next-generation web application that empowers farmers using:

- AI-driven crop & soil recommendations  
- Smart inventory management  
- Weather intelligence  
- Crop disease guidance  
- Digital marketplace for trading  

It modernizes traditional farming with **data-driven, intelligent decision making**.

---

## ✨ Key Features

### 🤖 AI Assistant (Groq LLaMA)
- Ask natural farming queries  
- Get instant answers for crops, pests, soil, irrigation, weather  
- Personalized suggestions  

### 📦 Inventory & Asset Management

#### 🌱 Crops
- Track crops, growth stages, irrigation  
- Yield prediction  
- Crop analytics (bar charts)

#### 🧪 Pesticides
- Track chemicals, expiry, stock levels  
- Pesticide usage analytics (pie charts)

#### 🐄 Livestock
- Track cattle, health, feed usage  
- Vaccination tracker  
- Livestock analytics

#### 🛠 Tools & Machinery
- Track tools, service logs, condition  
- Predictive maintenance insights

#### 🍚 Consumables
- Manage seeds, fertilizers, feed  
- Low stock alerts

## ⚙️ Installation Guide

### 1️⃣ Clone the repository
```bash
git clone https://github.com/NavinkumarJ/Smart-Agricultural-Management-and-Trade-System.git
cd Smart-Agricultural-Management-and-Trade-System/samd-frontend
````

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Create `.env` file

Inside `samd-frontend/`:

```
VITE_GROQ_API_KEY=your_api_key_here
```

⚠️ **Never commit `.env`** — GitHub push protection will block secrets.

### 4️⃣ Start development server

```bash
npm run dev
```
